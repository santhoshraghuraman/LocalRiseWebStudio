# Local Rise Web Studio

**Local Rise Web Studio** is a modern digital solutions studio helping businesses build a strong online presence through professional website development, mobile app development, digital marketing, and intelligent automation. We create responsive, high-performance websites, e-commerce platforms, and custom applications tailored to each client's needs.

## 🚀 Features
- **Cinematic 3D Intro:** A highly optimized WebGL opening sequence built with Three.js and GSAP, featuring custom 3D doors matching the brand's navy and gold aesthetics.
- **Premium UI/UX:** Clean, modern, and beautiful design layout tailored for conversion and ease of use.
- **Performance First:** 100% handcrafted architecture with zero bloat, lazy-loaded assets, and optimized bundle sizes ensuring a sub-second load time.
- **Mobile Responsive:** Fluid layout constraints and specific overflow guards providing a flawless experience across all devices (Mobile, Tablet, Desktop).
- **Tech Stack:** React, Vite, Tailwind CSS, TypeScript, Three.js, and GSAP.

## 📦 Setup Instructions

To get the project running locally:

1. **Clone the repository**
   ```bash
   git clone https://github.com/santhoshraghuraman/LocalRiseWebStudio.git
   cd LocalRiseWebStudio-main
   ```

2. **Install dependencies**
   ```bash
   npm install --legacy-peer-deps
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Build for Production**
   ```bash
   npm run build
   ```

## 🛠 Project Structure

- `src/components/` - Reusable UI elements, including the cinematic `DoorIntro3D.tsx`
- `src/assets/` - Brand-specific images and local fonts
- `src/data/` - Content configuration for Portfolio, Services, Pricing, and more
- `src/App.tsx` - Main application container
- `src/index.css` - Global styles and Tailwind configuration
